# Skill: Programmatic UI vs Real Capture

## 默认
能准确复现、且真实 UI 本身不是内容重点时，优先程序化 UI。

适合程序化复现：
- 浏览器外框、地址栏、加载状态
- 终端窗口
- HTTP request/response 面板
- 文件/代码编辑器的抽象界面
- 聊天气泡、设置页等示意 UI

适合真实录屏：
- “真的输入 baidu.com 后页面出现”这种真实行为
- 某个软件具体按钮/交互就是知识点本身
- 需要证明某个现象确实存在

## 目标
减少重复手工录制，但不为了省事牺牲可信度。

程序化 UI 必须：
- 文案准确
- 布局像真实产品逻辑，不做 AI 风假 UI
- 不伪造会被观众误认为真实截图的数据
