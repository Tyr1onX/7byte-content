# Skill: Cover Design

用于 7BYTE 每期 3:4 / 4:3 封面的生成与发布前审计。

## 基本原则

- 封面首先服务于缩略图识别，不是把视频画面直接搬到封面。
- 固定品牌：权威头像 + `7BYTE`、黑/炭灰、暖白、少量 `#D8FF68`。
- 一张封面只保留一个主标题和一个主视觉关系。
- 3:4 与 4:3 必须分别排版，禁止仅靠等比缩放或固定比例坐标复用。

## 图标规则

- 核心语义图标禁止临时用圆弧、线段等手工近似拼接。
- 优先使用项目既有 SVG/Lucide/权威图标资产；若需要自绘，必须先作为独立图标组件完成视觉审计，再进入封面。
- Wi-Fi、路由器、互联网等图标必须检查：轮廓完整、中心对齐、线宽一致、缩小后不出现多余弧线/断线/粘连。
- 图标不能因为缩放或裁切产生超出卡片边界的装饰线。

## 文字布局规则

- 所有文字必须依据实际 bounding box 排版，不得仅用固定百分比坐标猜位置。
- 文字块必须有明确最大宽度、内边距和最小安全间距；超宽时应缩字号或换行，禁止把文字挤到图标/卡片边缘。
- 图标 + 标题 + 副标题组合必须作为一个 layout group 计算，而不是各自独立写死 x/y。
- 中英文、数字、箭头等混排后必须再次检查真实像素宽度。

## 强制双比例审计

每期必须分别检查 3:4 与 4:3，不能用其中一张代表另一张。

至少检查：

1. 原尺寸：标题是否完整、视觉层级是否成立。
2. 50% 缩放：图标是否仍清楚，文字是否开始拥挤。
3. 25% 缩略图：是否仍能一眼看出主题。
4. 检查所有图标是否有异常弧线、断线、重叠、越界。
5. 检查所有文字是否被挤偏、贴边、与图标抢空间。
6. 检查主视觉是否只表达一个关系，不堆多层说明。

任一比例发现问题都回到布局源文件修复，禁止只对最终 PNG 打补丁。

## EP002 事故记录

EP002 第一版发布封面出现：

- 路由器 Wi-Fi 弧线由 Pillow 临时手绘，圆弧几何和卡片比例不匹配，缩小后明显不自然；
- `路由器 / 无线接入` 使用固定比例坐标，没有基于真实文字 bounding box 与图标共同排版，导致文字被挤向右侧；
- 生成后只确认“文件存在”，没有对 3:4 / 4:3 成品做独立缩略图视觉审计。

根因不是单个坐标错误，而是缺少 **权威图标资产 + 内容感知布局 + 成品视觉 QA** 三道约束。以后封面交付前必须同时通过这三项。
