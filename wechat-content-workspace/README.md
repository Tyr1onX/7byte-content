# 闻舟会用公众号内容工作区

这个目录用于沉淀公众号“闻舟会用”的内容生产、归档和草稿自动化准备。

## 当前定位

- 账号名称：闻舟会用
- 账号简介：讲清手机应用、人工智能和数字生活里的新科技，让新东西真正用得上。
- 内容方向：手机微信技巧、AI 生活应用、数字生活办事、防骗安全指南、新科技乐趣。
- 前台表达：不长期强调“老人/银发”，默认面向不熟悉新科技的人。

## 固定流程

```text
选题 / 数据
  ↓
生成 Markdown 正文
  ↓
生成封面图与摘要
  ↓
转换公众号 HTML
  ↓
上传封面图和正文图片
  ↓
调用公众号接口创建草稿
  ↓
人工检查、勾选原创声明、发布或定时群发
```

## 目录说明

```text
config.json              公众号固定配置，不包含密钥
topics/                  选题池
archive/                 已恢复旧稿与发布状态索引
articles/                后续正式生产稿
templates/               公众号 HTML 模板
tools/                   草稿创建脚本
```

## 当前边界

- 不模拟网页登录。
- 不绕过扫码。
- 不保存 Cookie。
- 不在仓库写入 AppSecret、access_token 或登录态。
- 系统只创建草稿，最终发布由人工完成。

## 下一步

1. 在公众号后台确认开发者 AppID / AppSecret 与 IP 白名单。
2. 本地通过环境变量配置密钥。
3. 用 `tools/create_wechat_draft.py` 从 Markdown 创建草稿。
4. 后台检查草稿，手动处理原创声明与最终群发。
