# Design Notes — 空桌面但风扇高速

## 数据驱动目标
EP015 约 85h：1602 播放、2s 跳出 31.68%、5s 播放率 31.97%、完播率 3.22%、平均播放 5s、平均播放占比 19.11%。EP015 的第一秒数字冲突有效改善了前 2 秒，但 3–8 秒仍明显流失。

EP016 的唯一实验变量：**把第二个有效信息点提前到第 6 秒前**。不再只盯总时长。

## 画幅与空间
`1920×1080 / 60fps`。主视觉保持在 `y=-360..300`，底部字幕带不放关键卡片。canonical header / watermark / outro 完全复用。

## Hook
第一稳定帧必须直接出现：
- `NO APP WINDOWS`
- `CPU ↑`
- `FAN HIGH RPM`
- `没窗口 ≠ 没任务`

第一句直接排除“风扇坏了”的直觉；第二信息点“没窗口，不等于CPU没任务”必须在第 6 秒前完成。

## 视觉路线
1. 空桌面 + CPU spike + 风扇高转速，立即给“没窗口 ≠ 没任务”。
2. 后台任务示意：Windows Update / Defender / Search Index 三行资源占用，强调都是“后台”。
3. 立刻给操作：`Ctrl + Shift + Esc` → Task Manager → `CPU ↓` 排序。
4. 两种处理：`偶尔几分钟 → 先观察`；`长期高占用 + 高温 → 继续排查`。

## 本期实验目标
- 目标完整成片约 `27–30s`。
- 第二个有效信息点必须在 `6s` 前完成。
- Task Manager 行动建议尽量在 `15s` 前进入。
- 目标：2s 跳出 `<30%`；5s 播放率 `>40%`；平均播放 `>7s`。

## Production 决策
- V1 Production Build `35291664499` 全绿，第二信息点 `5.303s`、Task Manager `13.671s`，但完整成片约 `31.783s`，主动拒绝作为最终候选。
- V2 Production Build `35292005967` 全绿，第二信息点 `5.500s`、Task Manager `12.987s`，完整成片约 `31.183s`，仍高于本期主动设定的 30 秒上限，因此继续压缩。
- V3 Production Build `35292278488` 全绿。第二信息点 `5.447s`，Task Manager 行动进入 `12.592s`，持续/偶发判断进入 `19.211s`。
- V3 正文结束 / canonical outro 起点 `25.341458s`，完整成片 `29.950000s`，进入本期目标区间。
- V3 作为 Final Candidate，等待用户人工看片确认。
