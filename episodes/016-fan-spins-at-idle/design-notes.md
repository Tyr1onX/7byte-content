# Design Notes — 空桌面但风扇高速

## 数据驱动目标
EP015 约 85h：1602 播放、2s 跳出 31.68%、5s 播放率 31.97%、完播率 3.22%、平均播放 5s、平均播放占比 19.11%。EP015 的第一秒数字冲突有效改善了前 2 秒，但 3–8 秒仍明显流失。

EP016 的唯一实验变量：**把第二个有效信息点提前到第 6 秒前**。不再只盯总时长。

## 画幅与空间
`1920×1080 / 60fps`。主视觉保持在 `y=-360..300`，底部字幕带不放关键卡片。canonical header / watermark / outro 完全复用。

## Hook
第一稳定帧必须直接出现：
- `NO APP WINDOWS`
- `CPU ↑`
- `FAN HIGH RPM`
- `没窗口 ≠ 没任务`

第一句：`什么都没开，风扇突然狂转，很多时候不是风扇坏了。`
第二句在第 6 秒前完成：`没窗口，不等于CPU没任务。`

## 视觉路线
1. 空桌面 + CPU spike + 风扇高转速，立即给“没窗口 ≠ 没任务”。
2. 后台任务示意：Windows Update / Defender / Search Index 三行资源占用，强调都是“后台”。
3. 立刻给操作：`Ctrl + Shift + Esc` → Task Manager → `CPU ↓` 排序。
4. 两种处理：`偶尔几分钟 → 先观察`；`长期高占用 + 高温 → 继续排查`。

## 本期实验目标
- 目标正文约 `22–25s`，完整成片约 `27–30s`。
- 第二个有效信息点必须在 `6s` 前完成。
- Task Manager 行动建议尽量在 `15s` 前进入。
- 目标：2s 跳出 `<30%`；5s 播放率 `>40%`；平均播放 `>7s`。
