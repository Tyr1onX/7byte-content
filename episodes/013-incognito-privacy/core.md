# Core — 无痕浏览能保护什么

## 核心问题
浏览器无痕模式为什么不会在本机保留普通浏览历史，却不等于匿名上网？

## 观众最终只需要记住
无痕主要减少浏览会话结束后留在本机的浏览数据，不负责隐藏网络身份。下载文件和保存的书签仍可能留下；访问的网站及网络提供方仍可能观察到活动。

## 事实链路
1. Chrome 无痕窗口使用独立的临时浏览会话，关闭所有无痕窗口后，Chrome 不保留该会话的普通浏览历史、Cookie 和网站数据。
2. 用户主动保存的下载文件与书签不会因为关闭无痕窗口自动消失。
3. 无痕不提供匿名网络功能；网站、雇主或学校的网络以及互联网服务提供商仍可能观察活动。具体可见内容取决于连接和加密，不声称他们都能看到全部页面内容。
4. 登录网站后，网站仍可以根据账户识别该用户。无痕不阻止所有跟踪。

## 关键概念
- 无痕模式：限制会话数据留存的浏览模式，而不是匿名身份。
- 浏览历史：浏览器本地记录的访问页面列表，不等于网络上所有访问记录。

## 本期边界
不讨论 VPN、Tor、DNS 日志或取证恢复方法；不声称无痕可以清除其他设备、网站或网络已有的记录。

## 事实核验
- Google Chrome Help, Browse in Incognito mode: https://support.google.com/chrome/answer/95464?hl=en
- 官方说明确认会话结束后本机历史/网站数据不保留，下载与书签保留，以及网站和网络管理方仍可能观察活动。
- 核验日期：2026-09-09。
