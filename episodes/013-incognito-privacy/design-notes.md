# Design Notes — 无痕模式

## 数据驱动目标
EP012 约36小时：933播放、2s跳出39.60%、5s完播28.40%、平均5.99秒。前两秒和中段均弱；不能仅凭这些数据归因发布间隔。保持约48小时运营节奏，换具体日常场景、减少协议术语。

## 画幅与空间
1920×1080 / 60fps。浏览器与网络关系适合横版。主视觉 y=-360..300，底部 y=320..500 为字幕保留带。固定品牌层不变。

## Hook
第一稳定帧直接给“无痕 ≠ 匿名”，同时显示“本机历史不保留 / 网络并非匿名”。口播直接说结论。第二信息推进在下载与书签出现时完成。

## 视觉
程序化浏览器窗口、文件、书签、网站与网络节点。只有一个主运动对象。使用仓库品牌色，不重画官方 Chrome 标志；无痕窗口用通用浏览器隐私图标表示。禁止假装真实用户数据。

## 边界
不把无痕描述成完全不留痕；不说所有网络方都能看见全部页面内容。真实产品行为以 Chrome 官方帮助为准。
