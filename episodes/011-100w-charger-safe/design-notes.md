# EP011 Design Notes

## 数据驱动目标
EP010 约 48h 数据：2s 跳出 `39.17%`、5s 完播 `36.26%`、平均播放 `9s`；明显弱于 EP009 的第一秒反常识 Hook。说明“直接给结论”还不够，下一期要把**具体数字冲突 + 可视证据**同时放进第一稳定帧。

## Hook
- 第一稳定帧直接显示 `100W MAX`、`25W LIMIT`、`≈25W` 三个数字关系。
- 大标题只写：`100W，不会硬塞进手机`。
- 不用“会不会充坏？”作为首屏唯一信息；问题可以进入标题/封面，但视频第一秒先给答案和证据。

## 画幅
- `1920×1080 / 60fps`。
- 关系型解释，继续横版。
- 主视觉保持 `y=-360..300`，底部 `y=320..500` 留给自动字幕。

## 视觉语义
- 充电器 / Source：中性暖白 + amber，表达“能力上限”，不是危险。
- 手机 / Sink 与已协商结果：品牌绿。
- 限功率因素：电池 amber、温度 red 仅作状态提示、线材 blue；不做霓虹。
- 核心不是闪电特效，而是 `MAX → REQUEST → NEGOTIATED` 的关系变化。

## 动效
- 一次只动一个主要对象。
- 协商链用稳定三步卡，不让 Source/Sink 跨 shot 跳位置。
- Shot 之间直接 ownership 切换，不保留 root-level proxy。
- 关键结果至少停留 0.8s。

## 刻意不展开
- PPS / EPR。
- 私有快充协议兼容矩阵。
- 电芯内部充电曲线。
