# EP004 Script

## V1 口播

买了一块 500GB 硬盘，插进电脑却只剩 465GB。少掉的 35GB 去哪了？其实硬盘没缩水。

厂家标容量时，1GB 按 10 亿字节算，所以 500GB 就是 5000 亿字节。

但 Windows 显示容量时，长期习惯按 1024 进制换算：1024 字节是 1KB，1024KB 是 1MB，再除一次 1024 才到它显示的 1GB。严格来说，这个单位其实更接近 GiB。

于是同样的 5000 亿字节，除以 1024 的三次方，大约就是 465.7。

格式化和系统分区还可能再占一点，所以你看到 465GB 左右完全正常。硬盘没少，只是两边用的尺子不一样。

这里是 7BYTE，把计算机讲简单一点。

## 口播约束

- `500GB / 465GB / GiB / 1024` 是技术 token，不在字幕中拆开。
- 画面可以写公式，但旁白不逐位朗读 `1,073,741,824`，避免拖节奏。
