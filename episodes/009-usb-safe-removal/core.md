# EP009 Core — U 盘真的不能直接拔吗？

## 核心问题

U 盘 / 移动硬盘为什么有“安全弹出”？直接拔到底危险在哪里？

## 观众最后只需要记住

**真正危险的不是“拔”这个动作本身，而是设备仍有未完成写入时突然断开。** “安全弹出”的核心作用，是让系统完成必要的写入收尾并停止继续使用设备。

## 事实链路

1. 外部存储在工作时，系统可能仍有尚未完成的写入；如果此时断开，当前文件、文件系统元数据或其他正在修改的数据可能丢失或损坏。
2. Windows 的“安全删除硬件”流程用于让相关写入完成并让系统停止使用该设备。
3. Windows 10 版本 1809 起，外部存储默认删除策略改为 **Quick removal / 快速删除**。微软说明该策略会以“设备随时可移除”为目标管理存储操作，并关闭 Windows 侧的磁盘写入缓存，因此在设备空闲时，不经过“安全删除”直接断开的风险比旧默认策略低。
4. 另一种 **Better performance / 更好的性能** 策略允许 Windows 缓存外部设备写入；微软明确要求在该策略下使用“安全删除硬件”，以确保缓存操作完成。
5. 即便默认是快速删除，微软面向普通用户的支持文档仍建议在断开 U 盘 / 外置硬盘前使用“安全删除硬件”，这是最稳妥、最容易执行的习惯。

## 本期边界

- 不说“现在 U 盘都可以随便拔”。
- 不把“安全弹出”说成只是在关电；它首先是写入与设备使用状态的收尾。
- 不展开 USB 协议、SCSI 命令、文件系统 journaling、设备内部缓存实现。
- 不保证看到“空闲”就绝对没有任何设备内部活动。

## 官方依据

- Microsoft Learn — Manage default media removal policy：Windows 10 1809 起默认 Quick removal；Quick removal 不使用 Windows 磁盘写入缓存；Better performance 需要安全删除。
- Microsoft Support — Safely remove hardware in Windows：为避免数据丢失，断开 USB 闪存盘和外部硬盘前建议安全移除。
