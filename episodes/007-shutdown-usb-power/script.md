# EP007 Script — 电脑关机后，为什么鼠标键盘还亮着？

电脑都关机了，鼠标键盘怎么还亮着？它没关干净吗？

多数情况不是。关机和断电，是两回事。

桌面机只要电源还接着市电，ATX 电源里通常还有一路 `+5VSB` 待机供电在工作。

主供电关了，它仍能给开机按钮、唤醒电路和部分 USB 端口供电。所以系统已经关机，鼠标灯、键盘灯，甚至 USB 充电仍然可能继续。

如果不想让它亮，可以进 BIOS 找 `ErP Ready`、`USB Power in S5` 一类设置。不同主板名字会不一样，也可能顺带关闭关机充电或唤醒功能。

真正完全断电，是切断交流电源后的 G3。

记住：关机，不等于物理断电。
