# EP007 Design Notes

## 数据驱动目标

EP006 发布约 15 小时后的早期数据：播放 `6205`、2s 跳出 `27.56%`、5s 完播 `36.32%`、平均播放 `8s`、完播率 `2.91%`。

本期判断：开头已经继续变强，下一阶段主要优化第 8 秒之后的留存。因此 EP007 保持问题式 Hook，但把核心机制更快讲出来，目标完整成片约 `36–42s`。

## 发布节奏锁定

- 当前抖音默认：约 `48h` 一期。
- EP006 发布：`2026-08-26 18:00`。
- EP007 计划窗口：`2026-08-28 18:00` 左右；实际发布日期以平台发布记录为准。
- 不再把发布频率作为本期内容实验变量。

## 画幅与空间契约

- `1920×1080 / 16:9 / 60fps`
- 主视觉约 `y=-350..280`
- 字幕保留带约 `y=320..500`
- 横版关系/电源链路解释继续使用成熟横版母版。
- `project.meta == capture == final output`
- Scene 不绘制 canonical 左上角 header；最终 composite 唯一 overlay。

## 品牌层

完全复用横版品牌锁：背景、中央水印、canonical header、canonical horizontal outro、Yunyang `-5%`、品牌句与 outro 同帧起步。

## 主视觉语言

必须保留真实可识别实体：
1. 已关机的桌面电脑与发光鼠标/键盘。
2. ATX 电源与 `+5VSB` 待机轨。
3. 主板 + USB 分支。
4. 简化 BIOS/UEFI 设置页。
5. 交流电切断后的 G3。

核心视觉记忆：

`电脑关机` → `交流电仍接通` → `主电源 OFF / +5VSB ON` → `USB 仍可能供电` → `BIOS 可控制` → `G3 才完全断电`

## 画面文字职责

允许：`系统已关机`、`交流电仍接通`、`Main Rails OFF`、`+5VSB ON`、`USB Standby`、`ErP Ready`、`G3 Mechanical Off`、`关机 ≠ 物理断电`。

不把完整口播复制进画面。

## 技术准确性边界

- 不说“所有关机都会进入 S5”；Fast Startup 的细节本期不展开。
- 不说所有主板都会给所有 USB 口供电。
- 不承诺所有主板都有同名 ErP 设置。
- 不说关闭 ErP 以外的某个固定选项对所有型号都有效。
- 明确提醒设置可能同时影响关机充电、唤醒等功能。

## Motion 语气

- 主要状态变化 `0.6–1.0s`。
- 一次只有一个主运动对象。
- 电源路径用稳定轨道/条带表达，不做发光粒子。
- Shot 切换直接语义切换，不做复杂 matched geometry。

## 字幕

- 7BYTE Auto Subtitle Skill。
- Hook 第一 cue 由大标题完整承担，T0→T1 抑制普通字幕。
- 品牌句从最后 marker 起抑制普通字幕。
- 技术 token `BIOS / ErP Ready / USB / G3` 不拆。
