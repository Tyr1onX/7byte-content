# EP002 口播稿

Wi-Fi 明明是满格，为什么网页还是打不开？

因为 Wi-Fi 满格，和能不能上网，其实是两回事。

你手机上的 Wi-Fi 图标，主要反映的是手机到路由器这一段的无线信号。

所以就算它满格，也只能说明你离路由器够近，信号够强。

但真正打开一个网页，还得继续往后走。

路由器要连上运营商网络，DNS 要找到网站地址，最后还得真的连得上网站服务器。

所以宽带断了、DNS 出问题，或者网站自己挂了，你的 Wi-Fi 都可能还是满格。

下次遇到这种情况，先试试其他网站，再看看同一个 Wi-Fi 下，其他设备能不能上网。

如果大家都上不了，大概率问题不在你的手机。

所以记住：Wi-Fi 满格，不等于互联网畅通。

它只说明，你和路由器之间这一小段路，信号很好。

这里是 7BYTE，把计算机讲简单一点。
