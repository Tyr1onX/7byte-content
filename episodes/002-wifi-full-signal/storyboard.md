# EP002 Storyboard

目标时长：约 60–70 秒正文 + canonical 片尾。

## 0–5s — Hook
- 主信息：Wi-Fi 满格 ≠ 一定能上网。
- 画面：手机 Wi-Fi 四格全满，但浏览器加载失败/持续转圈。
- 主运动：浏览器 loading，随后出现一个克制的 `×`。

## 5–16s — 只说明手机到路由器
- 手机保持上方，路由器在下方出现。
- 两者之间无线链路变亮。
- 旁边只保留一句视觉结论：`信号满格 = 这一段很好`。
- 不展开协议。

## 16–31s — 真正的上网链路
- 画面向下展开：`手机 → 路由器 → 运营商网络 → DNS → 网站服务器`。
- 稳定元素：手机和路由器位置连续，不换实体。
- 主运动：一枚数据包沿纵向链路向下移动。

## 31–45s — 三种故障，但 Wi-Fi 仍满格
按顺序一次只展示一个故障：
1. 路由器之后的宽带链路断开。
2. DNS 节点失败。
3. 网站服务器失败。

每次顶部手机的 Wi-Fi 图标始终保持满格，以强化反差。

## 45–57s — 简单排障
- 画面切成同一 Wi-Fi 下两台设备。
- 情况 A：两台都失败 → 更可能是路由器/网络侧。
- 情况 B：只有当前手机失败 → 更可能是当前设备侧。
- 不做完整网络排障教程。

## 57–结束 — 结论
- 回到最简单的 `手机 ↔ 路由器` 关系。
- 大字：`Wi-Fi 满格 ≠ 互联网畅通`
- 小字：`它只说明你和路由器之间这一小段路信号很好。`
- 旁白进入“这里是 7BYTE”时再接 canonical 片尾。
