# EP006 Idea — 为什么电脑刚开机，内存就占了一半？

## 本期只回答一个问题

Windows 电脑刚开机，明明没有主动打开多少软件，为什么 16GB 内存可能已经用了七八个 GB？

## 一句话答案

因为“已使用”不只算可见应用；Windows 本身、内核、驱动、后台服务和进程工作集都要使用物理内存。与此同时，缓存/待机内存会被系统积极利用，但其中待机部分仍属于“可用”，需要时可以重新分配。

## 本期的认知反转

观众常把“空着的 RAM”理解成更健康。真正需要建立的判断是：**不要只盯开机占用了多少，更应该看可用内存是否长期很低，以及正常工作时是否持续满载并卡顿。**

## 与 EP005 的迭代关系
