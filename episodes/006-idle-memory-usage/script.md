# EP006 Script — 为什么电脑刚开机，内存就占了一半？

## 最终口播

**Hook**

16GB 内存，电脑刚开机，怎么就用了七八个 G？

**解释 1：已使用不等于可见软件**

因为“已使用”不只算你打开的软件。Windows 内核、驱动、后台服务和应用都在用内存，所以进程列表相加不一定对得上总数。

**解释 2：缓存**

再看“缓存”：最近用过的数据会留在待机内存，方便下次读取。

**核心反转**

但待机内存属于“可用”，程序需要时可以重新分配。

**判断方法**

所以别只盯开机占了多少。真正该看的是：可用内存是不是长期很低，开常用软件后是不是接近满载，而且明显卡顿。

**Canonical outro**

这里是 7BYTE，把计算机讲简单一点。
