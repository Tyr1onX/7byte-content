# EP006 Script — 为什么电脑刚开机，内存就占了一半？

## 最终口播方向

**Hook**

16GB 内存，电脑刚开机，任务管理器怎么就显示用了七八个 G？

**解释 1：已使用不等于可见软件**

因为这个“已使用”，不只统计你看得见的软件。Windows 内核、驱动、后台服务，还有各个进程的工作集，都要占物理内存。所以进程列表简单相加，本来就可能对不上整机占用。

**解释 2：缓存与可用内存**

再看下面的“缓存”。Windows 还会把最近用过的数据留在待机内存里，让下次读取更快。

**核心反转**

但这部分待机内存属于“可用”，程序真正需要时可以重新分配。

**判断方法**

所以别看到开机占了一半就急着清内存。真正值得担心的是“可用”长期很低，开几个常用软件就接近满载，还伴随明显卡顿。
