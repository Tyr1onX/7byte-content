# 口播稿 v4（录音版）

> 目标：正常、自然地说，整体控制在约 1 分钟附近，不为了卡秒数故意加速。
> 最终时间轴以实际录制音频为准；录音完成后，再让 Motion Canvas 的动画和字幕逐句对齐真实人声。

## 00:00–00:07 · Hook

你有没有想过，
在浏览器里输入 `baidu.com`，按下回车，
到网页真正出现之前，电脑到底干了什么？

## 00:07–00:20 · DNS

第一步，浏览器得先知道：百度到底在哪。

网络里真正用来找服务器的，
不是 `baidu.com` 这个名字，而是 IP 地址。

所以它会先去问 DNS：
“这个域名对应哪个 IP？”

DNS 把地址返回来以后，
浏览器才知道接下来该去找哪台服务器。

## 00:20–00:31 · 连接 + HTTPS

找到服务器以后，先建立连接。

如果是 HTTPS，
还会再建立一条加密通道，
后面的数据就通过这条通道传输。

## 00:31–00:38 · HTTP 请求

连接准备好以后，
浏览器才会真正发出 HTTP 请求。

`GET /`，你可以简单理解成一句话：
“把首页给我。”

## 00:38–00:51 · 资源返回

服务器收到请求以后，
就开始把网页需要的内容发回来。

HTML 负责页面结构，
CSS 负责样式，
JavaScript 负责交互，
图片这些资源也会继续加载。

## 00:51–00:56 · 浏览器渲染

浏览器拿到这些内容以后，
会一边解析，一边排版、绘制。

最后，网页才真正出现在你面前。

## 00:56–01:00+ · 总结 + 片尾

所以你以为自己只是按了一次回车，
背后其实已经完成了：
找地址、建连接、加密、请求、传输和渲染。

这里是 7BYTE，把计算机讲简单一点。
