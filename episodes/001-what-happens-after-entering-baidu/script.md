# 口播稿 v1

你有没有想过，当你在浏览器里输入 baidu.com，然后按下回车，这不到一秒的时间里，电脑到底干了什么？

第一步，它得先找到百度在哪。因为电脑真正通信靠的不是 baidu.com 这个名字，而是网络地址。所以浏览器会先通过 DNS，把域名找到对应的 IP 地址。

知道服务器在哪以后，浏览器会和它建立连接。访问 HTTPS 时，还会建立加密通信。

接下来浏览器才真正发出 HTTP 请求：把这个网页给我。

服务器收到请求以后，把网页需要的数据陆续发回来，比如 HTML、CSS、JavaScript 和图片。

浏览器再把这些内容解析、排版、绘制，最后你就看到了网页。

所以你以为自己只按了一次回车，背后其实已经完成了一整套互联网流程。

这里是 7BYTE，把计算机讲简单一点。
