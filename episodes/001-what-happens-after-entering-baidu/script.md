# 口播稿 v3

> 目标成片：约 58～62 秒。
> 语速：正常偏慢，画面跟着口播走，不赶知识点。
> 最终以实际录制口播音频为时间基准；下面时间点先作为 Motion Canvas 的节奏锚点。

## 00:00–00:07 · Hook

你有没有想过：

当你在浏览器里输入 `baidu.com`，然后按下回车，
看起来只是打开了一个网页，背后其实已经跑完了一整套互联网流程。

## 00:07–00:20 · DNS

第一步，浏览器得先知道：百度到底在哪。

因为网络通信真正要找的不是 `baidu.com` 这个名字，而是 IP 地址。
所以它会先去问 DNS：这个域名对应哪个 IP？
DNS 把地址告诉浏览器以后，它才知道该去找哪台服务器。

## 00:20–00:31 · 连接 + HTTPS

接下来，浏览器和服务器建立连接。
如果访问的是 HTTPS，还会先建立一条加密通道，后面的数据就在这条通道里传输。

## 00:31–00:38 · HTTP 请求

然后浏览器才真正发出 HTTP 请求：
`GET /` —— 把这个页面给我。

## 00:38–00:51 · 资源返回

服务器收到以后，会把网页需要的内容陆续发回来。
比如 HTML 决定页面结构，CSS 决定样式，JavaScript 负责交互，图片等资源也会继续加载。

## 00:51–00:56 · 浏览器渲染

浏览器一边收到这些数据，一边解析、排版和绘制。

最后，你才看到了这个网页。

## 00:56–01:00 · 总结 + 片尾

所以你以为自己只是按了一次回车，
实际上背后已经完成了：找地址、建连接、加密、请求、传输和渲染。

这里是 7BYTE，把计算机讲简单一点。
