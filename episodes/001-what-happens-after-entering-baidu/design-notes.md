# Design Notes

## 当前状态
EP.001 的首版视觉只视为技术原型。页面能运行不代表视觉方案成立。V2 起重新设计竖屏构图、浏览器 UI、节点样式和 motion language。

在用户明确认可 EP.001 的视觉质量之前：
- 不把本期组件提升到 `shared/`。
- 不把本期视觉细节固化成全局设计系统。
- 允许在本期内部快速重做，先证明效果，再谈复用。

## 这期不要什么
- 不用蓝紫渐变。
- 不用“赛博城市/粒子网络”。
- 不用小球代表所有网络对象。
- 不为了显专业展示 SYN/SYN-ACK/ACK；第一期只讲“大流程”。
- 不快速切 10 个独立卡片。
- 不使用大量裸 `x/y` 坐标拼一个桌面端信息图，再硬塞进 9:16。
- 不用自制的低质量假图标替代成熟图标资源。

## V2 竖屏构图
- 画布固定 `1080 × 1920`。
- 主内容安全宽度固定为 `912px`，左右各保留约 `84px`。
- 标题系统固定在上方；核心视觉舞台放在中部；解释性文字只占底部少量空间。
- 大型对象只使用少数稳定锚点：浏览器左下、DNS 右上、服务器右下。
- 浏览器从开头到结尾尽量保持同一个节点，避免换镜造成空间跳变。
- 重要元素不得依赖父级缩放后再用难以推算的子级绝对坐标完成布局；浏览器工具栏等内部 UI 使用 Motion Canvas `Layout` / Flexbox。

## 视觉语言
- 背景：接近黑色 `#10110F`。
- 主文本：暖白 `#F4F1E8`。
- 主强调色：`#D8FF68`，只用于步骤、网络状态和关键对象。
- 浏览器网页内容允许使用来源于真实产品语义的局部品牌色，例如搜索按钮使用接近百度的蓝色；这不应扩散成整期装饰色。
- 图标优先使用 Motion Canvas `Icon` 组件背后的成熟 Iconify 图标集；不要再用 `LOCK` 文字框之类临时替代物。
- 浏览器 UI 参考真实 Chromium 浏览器的结构，只复现知识点需要的部分：返回、刷新、地址栏、域名、页面主体。

## Motion language
- 动画必须解释因果：域名从浏览器出去 → DNS；结果回来 → 浏览器知道 IP；请求去服务器；资源回来后浏览器画面立刻发生变化。
- 网络阶段只允许一个主运动 packet，同一时间不要让多个无关物体乱动。
- 大型卡片进入使用 opacity + scale / spring 的组合，不再只做生硬平移。
- 普通路径移动约 0.9–1.2s，重要结果保留 0.4–1.0s 的阅读停顿。
- 资源返回按 HTML → CSS → JS → IMG 顺序，每一个都必须改变浏览器页面状态。

## 清晰度
视觉验收必须使用完整 `1080 × 1920`、`resolutionScale = 1`。Pages Player 的 `quality` 同样固定为 `1`。低分辨率预览只能用于性能调试，不能用于判断最终视觉质量。

## 真实 UI 决策
开头和结尾仍以高质量程序化 BrowserFrame 为首选，因为可控、可重复、不会泄露个人信息。如果后续对比发现真实录屏明显更自然，可只替换首尾真实浏览器片段，中间解释流程继续保持程序化动画。
