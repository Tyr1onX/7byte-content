# EP.001 字幕稿

目标：字幕跟随口播，但不把整段口播一次性塞进画面。每次只显示一个完整语义单元，最多两行；画面主视觉仍然是浏览器、DNS、Server 和 packet。

## 样式规则
- 固定在下方安全区，不跟随场景元素移动。
- 最大宽度约 `880px`，最多两行。
- 字号约 `36px`，暖白字，深色轻量底板。
- 不做逐字卡拉 OK，不做高亮跳字，不抢主动画。
- 上方标题负责“这一段在讲什么”，下方字幕负责“这一刻口播说了什么”。
- 片尾已经直接显示 `7BYTE / 把计算机讲简单一点。`，因此不再叠一层重复字幕。

## 当前字幕 cue

### 00:00–00:07 Hook
1. `你有没有想过？`
2. `当你在浏览器里输入 baidu.com，\n然后按下回车。`
3. `看起来只是打开了一个网页，\n背后却跑完了一整套互联网流程。`

### 00:07–00:20 DNS
1. `第一步，浏览器得先知道：\n百度到底在哪。`
2. `网络通信真正要找的不是域名，\n而是服务器对应的 IP 地址。`
3. `所以它会先去问 DNS：\n这个域名对应哪个 IP？`
4. `DNS 把地址告诉浏览器以后，\n它才知道该去找哪台服务器。`

### 00:20–00:31 连接 + HTTPS
1. `接下来，浏览器和服务器建立连接。`
2. `如果访问的是 HTTPS，\n还会先建立一条加密通道。`
3. `后面的数据，\n就在这条加密通道里传输。`

### 00:31–00:38 HTTP
1. `然后浏览器才真正发出 HTTP 请求。`
2. `GET / —— 把这个页面给我。`

### 00:38–00:51 资源返回
1. `服务器收到以后，\n会把网页需要的内容陆续发回来。`
2. `HTML 决定页面结构。`
3. `CSS 决定页面样式。`
4. `JavaScript 负责交互。`
5. `图片等资源也会继续加载。`

### 00:51–00:56 渲染
1. `浏览器一边收到这些数据，\n一边解析、排版和绘制。`
2. `最后，你才真正看到了这个网页。`

### 00:56–01:00 总结
1. `所以你以为自己只是按了一次回车。`
2. `实际上背后已经完成了：\n找地址、建连接、加密、请求、传输和渲染。`
