# EP.001 字幕稿 v2（录音版）

目标：字幕尽量忠实对应实际口播，不另写一套“总结文案”。当前先按口播稿 v4 拆分；录音完成后，再根据真实人声重新校准每一条字幕的出现和消失时间。

## 样式规则
- 固定在下方安全区，不跟随场景元素移动。
- 最大宽度约 `880px`，最多两行。
- 字号约 `36px`，暖白字，深色轻量底板。
- 每次只显示一个完整语义单元，避免一整段文字长期挂在画面上。
- 不做逐字卡拉 OK，不做高亮跳字，不抢主动画。
- 英文术语保留原写法：`baidu.com`、`IP`、`DNS`、`HTTPS`、`HTTP`、`GET /`、`HTML`、`CSS`、`JavaScript`。
- 片尾已经直接显示 `7BYTE / 把计算机讲简单一点。`，最终可不再重复叠字幕。

## 当前字幕 cue（时间仅为临时锚点）

### 00:00–00:07 Hook
1. `你有没有想过，`
2. `在浏览器里输入 baidu.com，按下回车，`
3. `到网页真正出现之前，\n电脑到底干了什么？`

### 00:07–00:20 DNS
1. `第一步，浏览器得先知道：\n百度到底在哪。`
2. `网络里真正用来找服务器的，`
3. `不是 baidu.com 这个名字，\n而是 IP 地址。`
4. `所以它会先去问 DNS：`
5. `“这个域名对应哪个 IP？”`
6. `DNS 把地址返回来以后，`
7. `浏览器才知道接下来\n该去找哪台服务器。`

### 00:20–00:31 连接 + HTTPS
1. `找到服务器以后，先建立连接。`
2. `如果是 HTTPS，`
3. `还会再建立一条加密通道，`
4. `后面的数据就通过这条通道传输。`

### 00:31–00:38 HTTP
1. `连接准备好以后，`
2. `浏览器才会真正发出 HTTP 请求。`
3. `GET /，你可以简单理解成一句话：`
4. `“把首页给我。”`

### 00:38–00:51 资源返回
1. `服务器收到请求以后，`
2. `就开始把网页需要的内容发回来。`
3. `HTML 负责页面结构，`
4. `CSS 负责样式，`
5. `JavaScript 负责交互，`
6. `图片这些资源也会继续加载。`

### 00:51–00:56 浏览器渲染
1. `浏览器拿到这些内容以后，`
2. `会一边解析，一边排版、绘制。`
3. `最后，网页才真正出现在你面前。`

### 00:56–01:00+ 总结
1. `所以你以为自己只是按了一次回车，`
2. `背后其实已经完成了：`
3. `找地址、建连接、加密、\n请求、传输和渲染。`

## 音频到位后的处理
拿到实际录音后，不再按上面的区间硬卡时间，而是以真实口播为唯一基准：
1. 先转写并确认实际说出的文本；
2. 标出每句话和关键词的真实时间点；
3. 把字幕 cue 对齐到对应语句；
4. 再让 DNS、HTTPS、`GET /`、HTML/CSS/JS/IMG、浏览器渲染等动画动作落在对应关键词附近；
5. 保留自然停顿，不要求整条视频严格等于 60.000 秒。
