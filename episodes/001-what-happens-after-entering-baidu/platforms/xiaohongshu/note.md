## 最终正文

你在浏览器输入 `baidu.com`，按下回车。

看起来只是“网页打开了”。
其实背后已经跑完了一整条链路👇

1️⃣ **先找地址**
`baidu.com` 是域名，网络还需要知道该去哪里。浏览器可能先查缓存；需要查询时，再通过 DNS 找到可通信的地址。

2️⃣ **建立连接**
拿到地址后，浏览器要先和服务器建立一条能传数据的连接。现代 Web 具体可能走不同传输协议，这里先记住“先连上”。

3️⃣ **HTTPS 建立安全通信**
如果是 HTTPS，还要建立安全层：加密数据、保护完整性，并验证服务器身份。

4️⃣ **发送 HTTP 请求**
连接准备好后，浏览器才真正开口要网页。`GET /` 可以先理解成一句话：**“把首页给我。”**

5️⃣ **服务器返回资源**
HTML 负责结构，CSS 负责样式，JavaScript 负责行为和交互，图片、字体等也可能继续通过后续请求加载。

6️⃣ **浏览器解析和渲染**
这些资源到手后，浏览器继续解析、排版、绘制，最后你才真正看到网页。

所以，一次回车背后其实是：

**找地址 → 建连接 → 安全通信 → 发请求 → 收资源 → 渲染**

这篇先把主链路串起来，不把 TCP / QUIC、TLS 握手、DNS 缓存层级一次塞满。

下一篇你更想先看：**DNS、HTTPS，还是“Wi-Fi 满格却没网”？**
