# Storyboard — USB-C 外形相同，能力不同

## Shot 1 — Hook
**时间：** 0 → `因为 Type-C 主要规定的是连接器`
- 两个外形完全相同的 USB-C 端口并排。
- 左侧连接显示器：`DISPLAY ✓`；右侧：`NO SIGNAL ×`。
- 标题：`同样 USB-C，功能可以完全不同`。
- 第一帧就建立“外形相同 / 结果相反”的冲突。

## Shot 2 — Connector ≠ Capability
**时间：** → `数据可能只是 USB 2.0`
- 中央 USB-C 图标稳定存在。
- 下方三项能力槽：`DATA ? / DISPLAY ? / POWER ?`。
- 结论：`USB-C = CONNECTOR`，功能要另看。

## Shot 3 — Data
**时间：** → `想输出画面`
- 同一 USB-C 接口分叉为 `USB 2.0` 与 `USB4` 两张数据能力卡。
- 不堆具体速率，重点表达“连接器相同，数据协议可以不同”。

## Shot 4 — Display
**时间：** → `充电则要看 USB PD`
- USB-C → 显示器。
- 两个合法视觉入口：`DP Alt Mode`、`USB4 Display`。
- 主信息：能不能出画面取决于设备是否实现显示能力。

## Shot 5 — Power + Cable
**时间：** → `所以买拓展坞`
- 左侧 `USB PD / POWER`，右侧 `CABLE CAPABILITY`。
- 同一根“Type-C 外观”下，能力标签不同。
- 说明：端口与线材都可能成为限制项。

## Shot 6 — Action
**时间：** → `这里是7BYTE`
- 三张检查卡：`数据` / `视频` / `供电`。
- 结论：`别只看 Type-C`。
- 结束状态稳定交给 canonical outro。
