# Design Notes — C盘越用越满

## 数据驱动目标
EP016 约 44h：播放约 1.03 万、2s 跳出 38.77%、5s 播放率 27.10%、完播率 1.63%、平均播放 5s、平均播放占比 16.52%。推荐页 99.5%。

这说明“常见异常 + 立刻能验证”的题材具备明显分发潜力，但第一句和 3–5 秒仍需要更快交付价值。

## 本期实验变量
1. **第一句话直接给答案**：不再先问“为什么”，而是先说“很多空间根本不是新装的软件”。
2. **操作路径提前**：`设置 → 系统 → 存储` 尽量在第 10 秒前进入。
3. 不再追求极端压短，目标是把正文控制在约 `21–24s`，完整成片约 `26–29s`。

## Hook
第一稳定帧：
- `NEW APPS: 0`
- `C: FREE 80 GB → 8 GB`
- `很多空间 ≠ 应用本体`

## 视觉路线
1. C 盘空间条快速从 80 GB free 收缩到 8 GB free，同时保持 `NEW APPS: 0`。
2. 空间来源分类：`WINDOWS UPDATE`、`TEMP FILES`、`RECYCLE BIN`、`SYSTEM & RESERVED`。
3. Windows Storage 风格分类页：Apps / Temporary files / System & reserved。
4. 行动卡：`设置 → 系统 → 存储`；再给 `临时文件 / 清理建议`，并明确 `不要直接乱删 Windows 文件夹`。

## 目标
- 2s 跳出：`<32%`
- 5s 播放率：`>35%`
- 平均播放：`>6.5s`
- 收藏率：保持 EP016 的实用型提升趋势。
