# Storyboard — C盘没装新软件，为什么还是越来越满？

## Shot 1 — 0–约 4.5s：没装软件，空间却掉了
- 第一稳定帧同时显示 `NEW APPS: 0` 与 C 盘 `80 GB FREE → 8 GB FREE`。
- 绿色结论：`很多空间 ≠ 应用本体`。
- 第一口播直接回答，不绕问题。

## Shot 2 — 约 4.5–10s：空间到底去了哪
- 四张紧凑分类卡依次出现：
  - `WINDOWS UPDATE`
  - `TEMP FILES`
  - `RECYCLE BIN`
  - `SYSTEM & RESERVED`
- 不给伪造精确 GB 数值，只表达“这些类别都可能占空间”。

## Shot 3 — 约 10–16s：先看分类
- Windows Storage 风格界面。
- 主路径：`Settings → System → Storage`。
- 分类条：Installed apps / Temporary files / System & reserved。
- 结论：`先看哪一类在长`。

## Shot 4 — 约 16s–body end：怎么清
- 左：`Temporary files`
- 中：`Cleanup recommendations`
- 右：红色提醒 `DON'T RANDOMLY DELETE WINDOWS`
- 结论：`先确认条目，再清理`。
- 品牌句起点同时切 canonical outro。
