# EP010 Idea — 电脑卡了，为什么“重启”比关机再开机更管用？

## 选题
Windows Fast Startup / Restart。

## 数据依据
EP009 把反常识结论直接放到第 1 秒后，2s 跳出降到 25.99%，5s 播放率升到 56.21%，平均播放时长升到 12s。EP010 保留这个前端策略，不再用“先完整提问再回答”的 Hook。

## 第 1 秒信息
**电脑卡了，别先关机——重启反而可能更彻底。**

## 核心认知
如果启用了 Windows Fast Startup，普通关机可以保存内核会话和部分驱动状态到休眠文件；Restart 不使用 Fast Startup，而是执行完整启动周期。因此排查驱动、更新或异常系统状态时，重启往往比“关机再开机”更有效。

## 边界
- 不是所有电脑都启用了 Fast Startup。
- 不说“关机是假关机”；用户会话仍会注销，机器也会断电到相应电源状态。
- 不建议为了排故长期关闭 Fast Startup；结论只落到“排故优先试 Restart”。
