# 7BYTE Motion Design System

## 核心原则

1. **一次只有一个主运动对象。** 允许辅助动画，但主注意力必须唯一。
2. **空间连续性优先。** 已经建立位置关系的电脑、DNS、服务器不要下一镜随意换位。
3. **动画表达因果。** 请求过去 → 响应回来 → UI 改变；不要只有“东西在飞”。
4. **关键结果要停。** 重要文本/结果出现后默认至少保留 0.6–1.2 秒阅读时间。
5. **运动速度偏慢。** 普通位移默认 0.8–1.4 秒；不要把 0.2–0.4 秒的飞入当默认。
6. **抽象与真实互相校验。** 如果前面解释了抽象机制，结尾尽量回到观众熟悉的真实结果。
7. **真实物体就像真实物体。** 数据用 packet/card 表示，网络用稳定路径，浏览器用浏览器结构；不要用发光球泛化一切。

## 视觉语言

默认色板：
- Background: `#111210`
- Surface: `#1B1D1A`
- Primary text: `#F3F1E8`
- Secondary text: `#A7AAA1`
- Accent: `#D9FF6A`
- Warning/error only when needed: `#FF745F`

每期可以调整强调色，但默认避免蓝紫 AI 风。

## 字体与层级

- 主标题：大、短、低字数。
- 说明文字：最多两行。
- 技术 token（DNS / GET / HTML）：等宽或明显区别于口播字幕。
- 不把整段口播直接堆在动画画面中。

## 转场

优先：淡入淡出、遮罩、沿已有空间关系推进、真实 UI 与抽象 UI 对齐 crossfade。

慎用：旋转转场、大幅 zoom、粒子爆炸、闪白、glitch。
