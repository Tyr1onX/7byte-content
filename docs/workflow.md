# Production Workflow

## 1. 讨论选题
先确定“观众看完只需要真正记住什么”。不要先写动画。

## 2. 口播脚本
口播先做到单独听也能理解，再设计画面。短视频优先口语化，不堆定义。

## 3. Storyboard
按时间段写：这一句口播时，屏幕上唯一的主信息是什么？

## 4. Design Notes
每一期自己决定：真实录屏比例、抽象程度、是否做 UI 仿真、强调色、镜头语气、哪些内容刻意不展开。

## 5. Animation Spec
把 storyboard 翻译成可执行参数：坐标、持续时间、先后关系、停留时间、状态变化。

## 6. Motion Canvas 开发
优先使用仓库 skills 和 shared 组件。时间、颜色、文案尽量 constants-first，方便 AI 和人修改。

## 7. 本地预览

```bash
npm install
npm run dev
```

浏览器中选择 episode，逐镜检查：可读性、节奏、空间连续性、是否有无意义运动。

## 8. 真实素材（可选）
真实 UI 有价值时用 OBS 录制。录屏不是默认义务；能用程序化 UI 准确复现并节省工作量时可以直接复现。

## 9. 剪映
最终合并真人口播、字幕、音效、真实录屏和 Motion Canvas 输出。

## Git 工作流
每一期/每次大改使用独立分支 + PR。不要直接在 main 上迭代视觉实验。
