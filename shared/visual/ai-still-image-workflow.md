# 7BYTE AI 静态视觉工作流

本文件定义 7BYTE 可跨平台复用的 **AI 静态图片生成能力**。它是共享工具层，不是新的全仓库视觉总管，也不会自动替换已经成熟的平台制作链路。

当前外部参考：`freestylefly/awesome-gpt-image-2` 的 `gpt-image-2-style-library` Skill。

## 1. 适用边界

默认适用：

- 小红书封面、知识卡、信息图。
- 公众号头图 / 文内解释图（任务明确需要时）。
- 其他平台的独立静态视觉实验（必须由对应平台规则显式启用）。

默认**不接管**：

- 抖音 / 通用短视频的 Motion Canvas 动画生产。
- `docs/workflow.md`、`docs/motion-design.md`、`skills/` 已定义的视频制作链路。
- `shared/brand/horizontal-video-brand-lock.md` 及既有视频品牌金标。
- 视频号对成熟视频母版的复用流程。

一个平台没有在自己的 `shared/platforms/<platform>.md` 中显式接入本工作流时，不得因为本文件存在就改变该平台现有做法。

## 2. 基本原则

1. **先选模板，再写生成提示词。** 不再为正式成品临时裸写一段散文式 Prompt。
2. **内容与视觉分层。** `core.md` 决定事实，平台文件决定表达，AI 图片只负责视觉呈现。
3. **品牌资产必须真实引用。** 需要 7BYTE Logo / 头像时，必须使用仓库或用户提供的官方资产作为参考图；不得让模型自行重画一个近似猫头像。
4. **可读性优先。** 图片中的信息模块、标题、箭头、标签必须比装饰重要。
5. **减少模型写长文。** 长正文放平台文案；图片只保留短标题、短标签和必要解释。
6. **人工审阅是发布门槛。** 生图成功不等于视觉通过。

## 3. 模板路由

优先使用 `gpt-image-2-style-library` 中的模板：

### 小红书 / 社媒首图

优先：`poster-layout-system`

目标：

- 强问题感 / 反常识感 / 场景感。
- 标题和主视觉在手机缩略图中仍能读清。
- 冷启动阶段允许同一选题先生成 2–3 个封面方向再人工选优。

### 技术解释 / 知识卡

优先：`infographic-engine`

目标：

- 一页一个主要结论。
- 通常控制在 3–5 个主要视觉模块。
- 用箭头、图标、结构图和留白代替长段文字。

### 品牌一致性探索

可参考：

- `brand-identity-package`
- `brand-touchpoint-board`

这些模板只用于建立 / 校准静态品牌触点，不得反向覆盖已经锁定的视频品牌规范。

## 4. 7BYTE 固定约束

跨平台可以复用：

- 官方 7BYTE Logo / 头像资产。
- “把复杂的东西，讲简单一点”这一类品牌价值表达（是否出现由平台决定）。
- 清晰的信息层级、真实技术语义、统一系列感。

不能强制跨平台复用：

- 某个平台的配色。
- 某个平台的构图密度。
- 页码、CTA、标题套路。
- 小红书当前测试中的黑 / 白 / 电光蓝视觉。

尤其注意：**小红书当前的 Image2 视觉实验不构成抖音视频的新视觉规范。** 抖音仍遵守自身品牌锁、视觉禁区和 Motion Canvas 规则。

## 5. 生成前 Visual Brief

正式生成前，当前平台目录建议维护 `visual-brief.md`，至少写清：

- 平台。
- 本篇目标（点击 / 收藏 / 解释 / 品牌识别等）。
- 需要的资产数量与画幅。
- 选用的模板。
- 必须使用的品牌参考资产。
- 必须出现的文字。
- 禁止出现的文字 / 元素。
- 与既有平台成品需要复用或隔离的部分。

## 6. 图内文案规则

禁止把创作者的内部思考、边界说明和防御性解释直接写进成品图，例如：

- “这里先只讲……”
- “不强制限定……”
- “这篇先把……串起来……”
- “下一篇再展开……”

如果某个技术边界确实会造成事实错误，应改成自然、用户可理解的准确表达，而不是把制作备注贴到图片里。

## 7. 发布前审阅

至少检查：

- Logo 是否为官方资产，而不是近似重绘。
- 系列页码 / 品牌位是否一致（若该平台需要）。
- 缩略图下标题是否仍可读。
- 中文是否有错字、乱码、重复字。
- 图示方向、协议关系、技术符号是否正确。
- 是否出现模型擅自添加的无关说明。
- 是否为了“科技感”牺牲信息清晰度。

## 8. 外部 Skill 接入

Codex 本地可安装：

```bash
npx skills add freestylefly/awesome-gpt-image-2 \
  --skill gpt-image-2-style-library \
  --agent codex \
  --global \
  --yes \
  --copy
```

仓库不复制该外部项目的完整模板库；这里只沉淀 7BYTE 自己验证过的路由规则、品牌约束和数据结论。
