# 小红书平台规则（已归档）

> **状态：停止运营 / 不再作为 7BYTE 的后续发布线路。**

自 2026-08-25 起，7BYTE 不再继续小红书冷启动、图文生产、视频适配、数据实验或发布优化。

## 硬约束

- 不再为新 episode 创建 `platforms/xiaohongshu/` 适配内容。
- 不再为了小红书审核修改、遮挡或降级已经完成的抖音 / 通用视频成片。
- 不再自动调用 `creator-buddy`、小红书热点、标题、图文或数据分析流程。
- 不再因为历史小红书实验反向修改抖音 Motion Canvas、封面、字幕、镜头、品牌锁或视频视觉语言。
- `episodes/*/platforms/xiaohongshu/` 中已经存在的文件只作为历史记录保留，不代表当前待办或可继续执行的运营计划。

2026-08-25 曾进行小红书冷启动测试，包括：

- EP001 图文知识卡测试。
- EP001 视频笔记复用测试。

这些实验不再继续。历史数据可以在需要复盘既往决策时读取，但不得据此自动恢复小红书运营。

## 与共享能力的关系

`shared/visual/ai-still-image-workflow.md` 仍可作为其他平台按需启用的静态视觉能力，但**不再由小红书作为默认使用场景**。

如果未来用户明确重新决定恢复小红书，必须先重新确认平台策略和生产方式；在此之前，所有 Agent 都应把本平台视为归档状态。
