# 7BYTE 固定视频工作流

## 固定品牌资产

以下两项从此作为长期资产，不再每一期重新设计：

1. **封面模板**
   - 固定：黑/炭灰底、暖白字、7BYTE 荧光绿点缀、左上角抖音头像 + 7BYTE。
   - 固定：标题区位置、主视觉卡片位置、底部 7-byte 方块签名。
   - 每期只改变：标题、kicker、关键词、主视觉中的具体内容。
   - 源文件：`shared/brand/cover-template.py`
   - 每期配置：`episodes/<episode>/cover/cover.json`

2. **统一动态片尾**
   - **唯一权威版本：EP001 V5 已认可成片中的片尾。**
   - 不再重新生成，不再根据头像/描述“复刻”一版。
   - 长期文件库位置：`/7BYTE/brand/7BYTE-outro-canonical-from-EP001-V5.mp4`。
   - 后续视频直接复用这个无声片尾资产，再在成片层加入当期旁白/BGM。
   - 片尾的头像尺寸、圆环、7 个 Byte 方块、`7BYTE_`、标语、终端提示、位置与节奏均冻结；除非用户明确要求品牌升级。
   - `shared/brand/outro-template.py` 仅负责复制 canonical 文件，不能绘制新版本。

## 每一期生产流程

1. 确定选题与口播稿。
2. 生成最终 AI 人声。
3. 按人声时间调整 Motion Canvas 动画。
4. 以 1080×1920 / 60fps 渲染无字幕正文。
5. 直接拼接 canonical 动态片尾，不重新生成片尾。
6. 进入剪映，用最终人声执行「识别字幕」。
7. 只在剪映内做字幕样式、BGM、音效和极小幅最终修整。
8. 用封面模板 + 当期配置生成 9:16 封面。
9. 同时输出一份 1080×1440 的缩略图检查版。
10. 发布前检查：头像、标题、首屏、末屏、音轨、60fps、无残留旧片尾。

## 文件存储

- **GitHub**：保存可复现源文件、封面模板、episode 配置，以及“片尾不得重做”的 canonical 规则。
- **ChatGPT 文件库**：保存最终成片、封面导出图、canonical 片尾和品牌系统 ZIP。
- **ChatGPT 工作沙箱 `/mnt/data`**：只是当前会话的工作副本，不等于用户电脑本地磁盘，不能当长期存储。
- **用户电脑本地**：只有用户主动点击下载后，文件才真正保存到电脑；建议本地也保留 `7BYTE/EP001` 与 `7BYTE/brand` 两个目录作为剪映/发布工作副本。
