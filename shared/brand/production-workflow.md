# 7BYTE 固定视频工作流

## 固定品牌资产

以下两项从此作为长期模板，不再每一期重新设计：

1. **封面模板**
   - 固定：黑/炭灰底、暖白字、7BYTE 荧光绿点缀、左上角抖音头像 + 7BYTE。
   - 固定：标题区位置、主视觉卡片位置、底部 7-byte 方块签名。
   - 每期只改变：标题、kicker、关键词、主视觉中的具体内容。
   - 源文件：`shared/brand/cover-template.py`
   - 每期配置：`episodes/<episode>/cover/cover.json`

2. **统一动态片尾**
   - 固定使用 `shared/brand/assets/douyin-avatar-384.jpg`，不再从历史图片中猜头像。
   - 固定顺序：头像进入 → 7 个 Byte 方块 → 7BYTE → 标语 → `>_` 微动 → 停留。
   - 固定 1080×1920 / 60fps / 5.4 秒。
   - 源文件：`shared/brand/outro-template.py`

## 每一期生产流程

1. 确定选题与口播稿。
2. 生成最终 AI 人声。
3. 按人声时间调整 Motion Canvas 动画。
4. 以 1080×1920 / 60fps 渲染无字幕成片。
5. 加入统一动态片尾。
6. 进入剪映，用最终人声执行「识别字幕」。
7. 只在剪映内做字幕样式、BGM、音效和极小幅最终修整。
8. 用封面模板 + 当期配置生成 9:16 封面。
9. 同时输出一份 1080×1440 的居中裁切版，用于主页/列表缩略图检查。
10. 发布前检查：头像、标题、首屏、末屏、音轨、60fps、无残留旧片尾。

## 文件存储

- **GitHub**：保存所有可复现源文件、品牌模板、episode 配置；不把频繁迭代的大视频塞进 Git 历史。
- **云端文件库**：保存最终成片、封面导出图、发布版素材。
- **本地**：保留与云端同名的 episode 目录，作为剪映和发布用工作副本。
