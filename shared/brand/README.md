# 7BYTE Brand System

这里保存 7BYTE 长期固定的品牌生产资产。

- `assets/douyin-avatar-384.jpg`：唯一权威头像副本，用于封面。
- `cover-template.py`：长期固定封面模板；只通过 episode 配置改变标题、关键词和主视觉信息。
- **片尾唯一权威版本不是重新生成的模板，而是用户已经认可的 EP001 V5 成片末尾。**
- `outro-template.py`：仅作为“复制 canonical 片尾”的保护脚本，禁止再根据描述重新绘制/重新生成片尾。
- `production-workflow.md`：固定视频生产与存储流程。

Canonical 片尾的长期文件保存在 ChatGPT 文件库：`/7BYTE/brand/7BYTE-outro-canonical-from-EP001-V5.mp4`。

原则：**封面模板稳定，片尾直接复用 canonical 成片。** 除非用户明确提出品牌升级，否则不要改动片尾头像尺寸、圆环、7 个 Byte 方块、`7BYTE_`、标语、终端提示、位置和节奏。
