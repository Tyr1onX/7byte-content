# 7BYTE Brand System

这里保存 7BYTE 长期固定的品牌生产资产。

- `assets/douyin-avatar-384.jpg`：唯一权威头像副本，用于封面/片尾生成。
- `cover-template.py`：长期固定封面模板；只通过 episode 配置改变标题、关键词和主视觉信息。
- `outro-template.py`：长期固定 5.4s / 1080×1920 / 60fps 动态片尾模板。
- `production-workflow.md`：固定视频生产与存储流程。

原则：**模板稳定，内容可变。** 除非明确做品牌升级，否则不要随 episode 改动头像、色板、固定布局和片尾节奏。
